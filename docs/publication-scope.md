# Publication Scope

This repository is the public dashboard codebase for Knowhere.

The public branch model is:

- `staging` is the published integration branch
- `main` remains available for production-oriented releases when needed

The repository keeps only public-safe source, workflows, docs, and examples.
Private secrets, private infrastructure values, and historical env files are removed from the published history.

The dashboard release workflow is intentionally scoped to the public repository and its documented GitHub secrets.
