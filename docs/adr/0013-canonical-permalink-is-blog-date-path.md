# Canonical Permalink is `/blog/YYYY/MM/DD/slug/`

Article home is `https://knowhereto.ai/blog/YYYY/MM/DD/slug/`. Cards, canonical, sitemap, and Share use that path. `blog.knowhereto.ai/YYYY/MM/DD/slug/` is honored with a redirect to the same date path under `/blog`. Slug-only public URLs and `/articles/$slug` are out.
