# Canonical Blog is `/blog`; the subdomain is advertising

Blog lives at `https://knowhereto.ai/blog`. Site Chrome “Blog” goes there. `blog.knowhereto.ai` is an advertising access point: the bare host redirects to `/blog`. We do not publish Article URLs on the subdomain. Existing `blog.knowhereto.ai/YYYY/MM/DD/slug/` URLs are still honored by redirecting to the matching Article on `/blog`.
